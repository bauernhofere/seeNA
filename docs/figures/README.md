# README illustration provenance

These three PNGs are generated by the executable root `README.Rmd`:

- `README-region-1.png`: two-fixture chr1 overlay, original 1–4 Mb coordinates.
- `README-profile-1.png`: sparse whole-genome view of example-a, with custom theme.
- `README-heatmap-1.png`: corrected-call categories, first 5 Mb of chr1/chr2/chrX;
  the fifth bin has no fixture input and is intentionally grey/NA.

**Only the existing files under `inst/extdata/` are read.** They are hand-authored
format fixtures from the initial package commit, not patients, fitted ichorCNA
outputs or biological simulations. See `inst/extdata/README.md` in the repository.
No signal is generated, perturbed, interpolated or filled to make denser images.
No clinical repository paths, selection manifests or patient-derived images are
used. The heatmap view subsets all aligned layers and coordinates together;
the complete matrix remains unchanged.

Rebuild from the repository root with `make readme` after `make bootstrap`.
The code uses this checkout via pkgload, knitr and ragg, plus optional heatmap
dependencies. Images use a 144-dpi device and ordinary system fonts; raster bytes
can vary across operating systems/dependency versions. Inspect images after a
rebuild rather than treating pixel hashes as biological validation.

Only these exact PNG filenames are allowlisted in `.gitignore`; general rendered
figures remain excluded. Do not replace the source inputs with clinical data.
README, source and PNGs should be updated together. They demonstrate API behavior
and presentation, not calling accuracy or final manuscript figures.
