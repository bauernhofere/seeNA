# README gallery provenance

These four PNGs are generated by the executable root [README.Rmd](../../README.Rmd):

- `README-heatmap-1.png`: 24 synthetic samples, grouped and sorted by metadata,
  with continuous segment-median logR across chromosomes 1–22 and X.
- `README-profile-1.png`: a genome-wide synthetic profile with 500 kb observations,
  call colors and segment medians.
- `README-region-1.png`: the first synthetic pair over chromosome 1, retaining
  the original observations and segment boundaries.
- `README-concordance-1.png`: the same pair with a 1 Mb directional agreement
  track; deliberately missing support remains grey.

## Data source

The [fixed-seed generator](../../inst/examples/make-demo.R) creates the inputs in
a temporary directory. All samples, metadata, CNA patterns and numerical
observations are synthetic. The [recipe](../../inst/examples/README.md) records
the signal formula, RNG policy, state templates and gap handling. These are
illustrations, not patient profiles, fitted ichorCNA outputs or biological
validation. No clinical data or clinical identifiers are read, transformed or
aliased to create this gallery. The small parser fixtures in `inst/extdata`
remain unchanged and continue to serve unit tests and help examples.

## Rebuild

Run `make readme` from the repository root after `make bootstrap`. The README
loads this checkout with pkgload, creates the synthetic files, imports them
through the public readers and renders the four images with knitr/ragg. The
same recipe is included in the installed package for users to run the examples.

Only the four exact PNG filenames are allowlisted in `.gitignore`; generated
raw files and other renderings remain ignored. Update source, README and images
together and inspect the rendered output. Images use system fonts, so raster
bytes can vary across operating systems and graphics-library versions.
